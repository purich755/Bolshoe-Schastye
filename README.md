# «Большое счастье» — демо главной страницы

Центр подготовки к школе и коррекции школьных трудностей, Казань, ул. Баки Урманче, 7.
Концепция «Из черновика — в чистовик»: тетрадь, которая становится аккуратнее по мере прокрутки.

Живой сайт: https://purich755.github.io/Bolshoe-Schastye/

## Запуск

```bash
node tools/serve.mjs 8577
```

Открыть http://localhost:8577. Сборки нет: `index.html`, `css/style.css`, `js/main.js`;
GSAP 3.13 (ScrollTrigger, MotionPath, Draggable) и Lenis 1.3.11 подключены с jsDelivr.

## Самопроверка

- `node tools/shots.mjs 1440` — прокрутка всей страницы, снимки разделов в `raw/shots/`, ошибки консоли, горизонтальное переполнение, «застрявшие» скрытые блоки. Флаги `--reduced`, `--pre` (прелоадер), `--only top,draft`.
- `node tools/interact.mjs 1440` — интерактив реальными событиями: самопроверка → текст WhatsApp, вкладки, лайтбокс, колода, FAQ, меню, якоря, высота кнопок.
- Проверено на 375 / 768 / 1440 / 1920 и с `prefers-reduced-motion`: ошибок нет, переполнения нет, 15–16 из 15–16 проверок.

## Что осталось заглушкой или требует подтверждения

- **ВКонтакте** закрыт анти-бот проверкой, оттуда ничего не взято.
- **Портрет педагога** — аватар аккаунта, а не фото с сайта центра: подтвердить, что это Ирина Рамилевна, и разрешение на публикацию.
- **«Мама, я сам!»** — иллюстрация шрифтом, не работа ученика (на странице так и подписано).
- **Яндекс-карта** — виджет по координатам из брифа; у виджета без oid бывает рекламный слот внизу.

## Факты, взятые сверх брифа

С прайс-листа самого центра (фото в Яндексе, действует с 01.07.2026): группа подготовки — до 5 детей,
коррекция почерка — до 4, занятия по 60 минут 2 раза в неделю, индивидуальное — 45 минут. Цены совпадают с 2ГИС.

## Вопросы клиенту

1. Часы работы (2ГИС и Яндекс расходятся) — сейчас на сайте только «по предварительной записи».
2. Фото Ирины Рамилевны и её должность/образование — можно ли указать.
3. Логопед: имя, фото, стоимость занятий.
4. Что такое «Игротека» — для кого и в каком формате.
5. Можно ли показать реальные работы «до/после» по почерку (с согласия родителей) — это усилит главную сцену.
6. Условия рассрочки и подарочного сертификата.
7. Ведутся ли ментальная арифметика и онлайн-занятия.
